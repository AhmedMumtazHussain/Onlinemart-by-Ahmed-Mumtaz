# Onlinemart-by-Ahmed-Mumtaz 
🛍️ Onlinemart --- E-Commerce Website

Onlinemart is a front-end e-commerce website built with HTML, CSS, and
JavaScript. It features a shopping-style homepage with product
categories, promotional sections, product listings, a search bar,
navigation links, and a cart entry point.

✨ Features

Shopping homepage with a navigation bar and promotional banner
carousel layout.

Product categories for home appliances, electronics, fashion,
stationery, toys, and more.

Product showcases including a "Best Sellers in Sports &
Outdoors" section.

Promotional product cards displaying deal labels, discounts, and
prices.

Search interface with a search input and search icon.

Shopping navigation with links for sign-in, account, orders, and
cart pages.

Reusable visual assets for product images, banners, icons, and
category cards.

Footer branding for Onlinemart.

Note: The supplied index.html defines the page structure and
references style.css, script.js, and an assets/ directory.
Search, carousel controls, cart behavior, and other interactive
features depend on the corresponding CSS/JavaScript and page files
being present and implemented.

🧰 Tech Stack

HTML5 --- page structure and content

CSS3 --- styling and responsive layout (via style.css)

JavaScript --- client-side behavior (via script.js)

repository URL.

2. Check the project files
